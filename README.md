# Практическая работа: Проект «Сервис по получению метеорологических данных»

## Функционал и преимущества сервиса:
* Удобный запрос через консоль. Программа является консольным клиентом к API Яндекс Погоды. Для использования необходимо предварительно получить ключ X-Yandex-Weather-Key у сервиса Яндекс Погода и вставить его в исходный код в строке №22 (WeatherService.java) - далее данный ключ будет передан в заголовок запроса. До момента получения метеорологических данных, программа запрашивает у пользователя в консоли:
  * Значение координаты lat (широта, в градусах) от -90 до 90 (например, 55.83);
  * Значение координаты lon (долгота, в градусах) от -180 до 180 (например, 37.61);
  * Желаемый параметр запроса limit (количество прогнозируемых суток, включая текущие сутки), который является целым числом от 1 до 7 (ограничение тестового тарифа API Яндекс Погода).
  
После того, как пользователь введет запрошенные данные - программа отправляет GET‑запрос с заголовком X-Yandex-Weather-Key (API-ключом) и таймаутом ожидания 10 секунд. Программа проводит проверку кода ответа сервера: при успехе выводится «HTTP 200 OK», а при неуспешном результате выводится его расшифровка (например, «HTTP 403 Forbidden»), тело ответа и завершается работа.

* Прозрачность работы с данными. Программа выводит JSON‑ответ сервера «как есть» целиком (без изменений и форматирования). Дополнительно, по желанию пользователя, программа может вывести ответ в читаемом отформатированном виде: у пользователя в консоли спрашивается (в пункте «5)») нужно ли вывести JSON-ответ в читаемом отформатированном виде и пользователь должен ответить «Да» или «Нет» (при этом, повторного запроса к API нет — данные берутся из сохранённого jsonBody). Ответ проверяется в цикле без учёта регистра. При опечатке пользователя: программа цитирует его ответ с сообщением о том, что такой ответ не предусмотрен, а затем вопрос задаётся пользователю повторно.

* Вывод в консоль текущей погоды и расчёт средней прогнозной погоды. Из JSON‑ответа извлекается текущая температура (fact.temp) и среднедневные прогнозные температуры (parts.day.temp_avg) для каждого дня с учетом выбранного пользователем параметра запроса limit (количество прогнозируемых суток, включая текущие сутки) и с учетом реально полученных данных по дням от сервиса Яндекс Погода (так как количество дней по которым реально получены данные может быть меньше чем выбранное пользователем количество дней в параметре limit). Затем рассчитывается среднее арифметическое от полученных среднедневных прогнозных температур. Дополнительно выводится справочная таблица «Дата — Среднедневная температура (°C)» по этим дням, чтобы пользователь видел, какие именно данные использовались в расчёте (внизу данной таблицы также для удобства выводится строка со средним арифметическим от среднедневных прогнозных температур).

* Интерактивный и защищённый ввод. Все параметры проверяются на соответствие установленным ограничениям и корректность: координаты — по физическим границам (lat от −90 до 90, lon от −180 до 180), а limit — как целое положительное число. Если введенное пользователем значение не является числом или выходит за пределы установленных ограничений, то программа выводит сообщение о соответствующей ошибке и просит повторить ввод, не допуская сбоев. При этом, программа учитывает ограничение тестового тарифа (максимум возможно запросить только 7-дневный прогноз), поэтому если пользователь запросил прогноз на более длительный срок, чем доступно (7 дней): программа выведет предупреждение, автоматически ограничив значение limit (7-дневным сроком) и честно сообщит, какое количество суток будет использоваться в расчетах.
